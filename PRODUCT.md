# PRODUCT.md

## Product name
Generator umowy kupna-sprzedaży samochodu

## Goal
Enable users to quickly generate a Polish car sale agreement by filling out a guided form.

## Core user problem
Users need a fast and structured way to prepare a sale agreement without manually editing templates.

## Primary user
Private individual selling or buying a passenger car in Poland.

## MVP value proposition
- guided step-by-step form
- fewer mistakes
- reusable saved drafts
- printable preview
- downloadable PDF

## Main user flow
1. User signs in
2. User opens dashboard
3. User starts a new contract
4. User fills seller data
5. User fills buyer data
6. User fills vehicle data
7. User fills sale terms
8. User confirms declarations and notes
9. User previews document
10. User generates PDF
11. User can return later and edit the draft

## Success criteria for MVP
- user can create and save a draft
- user can return and edit a draft
- user can preview a contract
- user can generate a PDF
- all records are scoped to the authenticated user

## Non-goals
- legal automation engine
- enterprise workflow
- organization management
- deep integrations with government or vehicle data sources
- e-signature and identity verification
